Full Stack Conf

A One-Day Conference About All Things JavaScript

See Speakers

Expert Speakers

Four developers from Kigali will lead the sessions. They build websites and apps for a living, and each of them chose a topic they use every week at work.

After every talk there is time for questions. If your project has a bug that has been bothering you for days, bring your laptop and ask.

The slides are short. Most of the time is spent writing code together.

About Full Stack Conf

Full Stack Conf is a one-day event for students and beginners who want to see how a whole JavaScript project fits together, from the database to the page in the browser.

Doors open at 8:30am and the first talk starts at 9:00. Lunch is included in the ticket, and the last session ends at 5:00pm.

You do not need to know all of the tools in the list. Most people come knowing one or two.

What you will Learn

  • MongoDB: NoSQL Database
  • Express: Framework for Node
  • React: JavaScript Library
  • Node JS: JavaScript Environment
  • ES2015: Latest JavaScript Version
  • Babel: JavaScript Compiler
